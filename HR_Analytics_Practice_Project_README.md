# HR Analytics – Practice Project

**Project Type:** Learning / Practice Project  
**Dataset:** 50,000 employees  
**Tools:** Excel, SQL

## Project Overview
This practice project uses HR analytics data to explore employee and workforce metrics.

## Work Completed
- Merged HR_1 and HR_2 datasets using EmployeeNumber / Employee ID.
- Practiced SQL queries to retrieve and filter employee-related records.
- Explored HR KPIs such as employee attrition and workforce metrics.
- Practiced interpreting data summaries to understand patterns.
- Reviewed how data can be organized and presented for reporting.

## Key Results
- Total Employees: 50,000
- Employees with Attrition: 25,105
- Overall Attrition Rate: 50.21%
- Avg Hourly Rate – Male Research Scientist: 114.45
- Average Monthly Income: 26015.78
- Average Years at Company: 10.77
